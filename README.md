# BTD6 Random Tower

A small browser-based Bloons TD 6 tower and crosspath randomizer.

## Requirements

- Node.js 18 or newer
- npm

## Start developing

```powershell
npm install
npm run dev
```

Open http://localhost:3110/ in your browser.

## Build

```powershell
npm run build
```

The build produces `dist/index.html` as a self-contained file with its styles, scripts, and favicon embedded. Open or drag that HTML file into a browser to use it offline. You can also serve the build with `npm run preview` on port 3110.
